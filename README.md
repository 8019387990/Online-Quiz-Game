\## How the Project Works



1\. Users register for a new account.

2\. Users log in using their registered credentials.

3\. JWT authentication securely verifies the user.

4\. The dashboard displays the available quiz categories.

5\. Users select a quiz category.

6\. Questions are displayed with a time limit.

7\. Users select their answers and complete the quiz.

8\. The application automatically calculates the score.

9\. The quiz result is saved in MongoDB.

10\. Users can view their score and result.

11\. Users can view their quiz history and performance statistics.

12\. Users can compare their performance with other users through the leaderboard.
