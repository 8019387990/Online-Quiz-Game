# QuizMaster – Online Quiz Game

QuizMaster is a full-stack online quiz application developed using the **MERN Stack**. It allows users to register, log in securely, participate in quizzes across multiple categories, view their scores, track quiz history, analyze their performance, and compare their results on the leaderboard.

## Features

- User Registration and Login
- Secure JWT Authentication
- Multiple Quiz Categories
- Timed Quizzes
- Instant Quiz Results
- User Profile
- Quiz History
- Performance Statistics
- Leaderboard
- Protected Routes
- User-specific Results
- Responsive User Interface
